# Claude Instructions for WellPharma Pharmacy Website

## Important Guidelines

### Git Workflow
- **NEVER push commits to GitHub without explicit user verification**
- Always create commits locally when changes are made
- Wait for user confirmation before running `git push`
- Ask: "Should I push these changes to GitHub now?" before pushing

### Project Structure
- Main website: index.html
- Styles: css/main.css
- Images: images/ directory
- WebP images: Image.webp/ directory
- Admin panel: admin-enhanced.html (for easy content updates)

### Deployment
- Site is hosted on Netlify
- Live URL: https://golden-kataifi-90edfd.netlify.app/
- Changes pushed to GitHub automatically deploy to Netlify

### Development Notes
- When updating categories/health tools, update both index.html and corresponding CSS classes
- Maintain existing color schemes unless specifically requested to change
- Test locally before committing changes

## How to Update Blogs

### Using Netlify CMS (Recommended):
1. Go to https://golden-kataifi-90edfd.netlify.app/admin
2. Login with your Netlify Identity account
3. Click "Blog Articles" → "New Blog Article"
4. Write and publish your post
5. Netlify automatically builds and deploys changes

### Blog System Architecture:
- **Markdown posts** stored in `_posts/` folder
- **Build script** (`scripts/build-blog.js`) converts markdown to HTML
- **Generated files**:
  - Individual blog pages in `/blog/` folder
  - JSON feed at `/api/posts.json`
- **Dynamic loading** on homepage and blog.html via JavaScript

### Manual Blog Updates:
1. Create markdown file in `_posts/` folder
2. Run `npm run build` to generate HTML files
3. Commit and push all changes

### Homepage Blog Carousel:
- Automatically shows latest 4 posts from `/api/posts.json`
- Static fallback content if build hasn't run yet

### Category HTML Location in index.html:
Look for: `<!-- Category Pills -->` around line 528-550

## Blog Writing Rules (apply to every new or edited post)

### Workflow
1. Zahraa researches in OpenEvidence or Doximity and pastes notes (or saves them in `_drafts/` using the template in `_drafts/README.md`)
2. Claude writes the post in `_posts/` following the rules below
3. Run `npm run build` and check the generated page before committing
4. Zahraa reviews the post before anything is pushed

### Facts & statistics
- Only use statistics and study findings that come with a source link provided by Zahraa (PubMed, journal, FDA, CDC, professional society). Never add a statistic, study, or citation from memory or general web results
- Link the source in the article text (e.g. "a [2024 study](link) found...")
- Check that each link opens the actual paper or guideline; if it doesn't, leave the claim out and tell Zahraa
- Describe findings accurately: say "surveyed women reported" vs. "studies show", note who funded a survey when relevant, and don't round numbers up
- Flag anything that sounds overstated ("clinically indistinguishable", "always", "cure") and soften it
- When a post discusses medications, never imply readers should stop or change a medication on their own; tell them to talk to their prescriber

### Plain language (no jargon)
- Write for an 8th-grade reading level: short sentences, everyday words
- If a medical term is unavoidable, define it right away in plain words (e.g. "FSH, a hormone that signals your ovaries")
- Give brand names alongside generic names (e.g. semaglutide (Ozempic, Wegovy))
- Keep Zahraa's warm, first-person pharmacist voice ("the way I'd explain it to a patient")

### AI-search structure (answer-first)
- One H1 (the title, generated by the build). Section headings (H2) are questions people actually search, e.g. "How do you know if it's perimenopause or anxiety?"
- Start each section with a 2–3 sentence direct answer (40–60 words), then the detail
- Put a short-answer summary near the top in `<aside class="summary-box" role="note">` (leave blank lines inside the aside so markdown still renders)
- Use bulleted lists for symptoms/options, numbered lists for steps, and markdown tables for comparisons (wrap tables in `<div class="table-scroll">` with blank lines inside)
- Add 3–5 questions in the `faq:` frontmatter (2–3 plain-sentence answers each); the build renders them on the page and as FAQPage schema. Answers must match the article
- Link to related WellPharma pages or tools (hormone kits, Hormone Quiz, Nutrient Calculator, birth control, GLP-1) where they genuinely help the reader
- End with the local call to action (phone, address, service areas) and the educational-purposes disclaimer

### Frontmatter checklist
- `title`, `date`, `author`, `image`, `excerpt` (1–2 sentences, accurate, no unsourced numbers), `category`, `tags` (plain list, no brackets), `faq`
- When revising a published post, set `updated:` to today's date — it shows "Last reviewed" on the page and updates dateModified in the schema
